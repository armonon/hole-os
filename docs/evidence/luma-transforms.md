# Native layer transforms

The connected editor calls retained `Studio.updateTransform(id, patch)` from Luma revision `af6f0893b6b0fe28fff2be99d7f3cb39ab6aba54` (`app/engine/studio.ts:4801`). The retained document contract (`app/engine/document.ts:160`) defines translation × rotation × horizontal shear × scale. X/Y position the layer's top-left origin. The engine stores radians; the UI explicitly converts edited degrees to radians. Positive rotation is clockwise in canvas coordinates. Signed scales flip around the same origin. This is not a center-preserving interactive transform gizmo.

The UI exposes bounded decimal fields and horizontal/vertical flip toggles, followed by explicit Apply. Only explicitly edited transform keys enter the engine patch. Existing other transform keys, source pixels, editable text, masks and unknown layer metadata remain intact. Undo uses the engine's real history. The native serializer's existing unknown top-level document limitation remains; original versions are retained.

Admission is native-only, unlocked top-level raster/text without smart sources, spatial presentation or shear. Document and selected backing surfaces are limited to 2048 pixels per edge/four million pixels. Offsets are ±2048, scale magnitudes 0.125–8, and edited angle ±180 degrees. The conservative transformed bounding box must remain within 2048 edge/four million pixels; text uses at least the full document bounds. Other imported transforms remain preserved, and unsupported targets can be edited in the full studio. Existing brush controls continue to refuse rotated, flipped or scaled targets.

Unapplied fields are recovery data rather than asset edits. Bounded per-layer strings (five keys, 32 characters each, at most 64 layers) preserve incomplete input such as `-` and empty fields. A coalesced snapshot uses the existing state.save/flush handshake, with a native recovery blob so the existing shell recovery chooser discovers field-only drafts. Restoring those drafts preserves `dirty:false` when no asset edit was applied. Layer switching retains each layer's values. Discard removes field drafts without changing the layer. Apply commits one engine history operation, then recovers the result. Recovery failure blocks close and retains visible work. Pending save acknowledgements block mutation.
