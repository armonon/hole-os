# Experimental local key estimate

`audio.key` saves `hole.key-analysis/1` JSON with exact immutable source/version, actual coverage, twelve-bin chroma, evidence measurements, six ranked candidate keys, a relative-major/minor alternative and raw score margin. Null key is a valid rejection result; no invented label substitutes for weak evidence. Output preserves source bytes and derives from the pinned version. Audio UI should say **Estimate key (experimental)**.

Original implementation uses the existing unmodified MIT FFT from demucs-web1.0.2; no native Sattari engine, fitted native profiles, GPL kernels or key model were copied. Formula sources: AudioLabs author documentation for [equal-tempered frequency/pitch mapping and chroma pooling](https://www.audiolabs-erlangen.de/resources/MIR/FMP/C3/C3S1_SpecLogFreq-Chromagram.html) and [template similarity](https://www.audiolabs-erlangen.de/resources/MIR/FMP/C5/C5S2_ChordRec_Templates.html). The latter describes chord recognition, not a validated key estimator; this implementation's key scoring is our original heuristic extension. No code copied from those notebooks.

Algorithm:22.05kHz decoded PCM,8192-point symmetric Hann window,2205-sample hop. Per-channel spectral energies sum independently to avoid stereo antiphase cancellation. Local peaks55–4000Hz above2% frame maximum, log-power parabolic frequency interpolation, nearest equal-tempered pitch atA4=440Hz, modulo12 pooling. Each accepted frame contributes normalized peak magnitude. A frame qualifies at RMS energy>1e-9 and spectral flatness<0.25. Original templates give seven scale tones0.35 baseline with tonic+1, third+0.6,fifth+0.5; both major and natural minor transposed to12roots. Cosine similarity ranks templates. Margin<0.08 or relative alternative gap<0.12 marks ambiguity; best score<0.7 declines key. These constants are transparent design heuristics, not fitted or calibrated probabilities.

Evidence gates: duration<6s, RMS<0.0001, fewer than25% tonal frames, fewer than4 pitch classes>=2.5% mass, or chroma entropy>0.94 decline a key. These gates do not establish that music is scientifically atonal; they mean this method lacks usable evidence. Sparse chords, modes, altered tuning, strong harmonics, percussion, modulation and relative key ambiguity remain limitations. No native parity or annotated music-corpus accuracy claim.

Bounds: first6–60seconds (default60); mono/stereo22.05kHz. Existing Action decoder accepts<=64MiB/10minutes/50million decoded samples, then key restricts channels and sample rate. Browser decoding may allocate before admission checks and cannot be interrupted within `decodeAudioData`. Analysis worker copies only selected<=60s, one activejob, hard1–10000ms deadline(default10s), termination on cancel/deadline, exact source duration/partial coverage retained after slicing. Analysis budget excludes browser decoding/storage. API: `HoleAudioKey.analyze(channels,22050,{signal,maxSeconds,budgetMs})`.
