# Bounded StemDeck dry timeline

Source: owned browser repository `sattari-seo-20261026/source`, pinned retained revision `ae9d4bfb82899e3b9d516a06d66b4915fc91b157`. No source AGENTS.md was found. The original browser/native studio remains available. This increment adds only `arrangementSchedule` and `linearGain` exports from the already bundled `arrangementModel.js`; the existing archive reader, modeled instrument voices and WAV writer are reused. No new runtime dependency, third-party license or native JUCE implementation is introduced.

The adapter exposes `transportInfo`, `play({position,loop,loopStart,loopEnd})`, `stop`, `seek`, `setMonitorLevel`, `renderTimeline` and `dispose`. Native clip timing, embedded PCM WAV offsets/rates, MIDI note pitch/time/duration/velocity, track/clip gain, pan, mute and solo drive actual browser audio. Explicit Play is required. The rendered stereo timeline is played by a browser buffer source with audio-clock loop points; seek replaces the active source. Monitor level is local playback state and does not rewrite the document. Save/reopen retains original archive audio, routing, automation, unknown properties and version lineage.

This is a **dry preview**, not full mix parity. Effects, routing, automation, clip fades, master processing and deck playback are preserved but not rendered. Linked/trimmed MIDI and sampler instruments are refused before playback. Compressed/non-WAV embedded audio requires the full studio; connected playback accepts mono/stereo PCM WAV at 8–96 kHz. WAV chunk and sample-count admission occurs before decode allocation. Limits are 60 seconds, 16 tracks, 128 clips, 512 notes and 16 million decoded samples; the pre-existing native archive limit remains 32 MiB. No audio fetch, microphone, cross-origin IndexedDB or hardware/native plugin access is added.

Preparation validates every source before scheduling. Stop invalidates preparation so a late decode/render cannot start playback; native browser offline rendering itself may finish internally after cancellation. A shared admission gate across adapter instances in the same sandbox remains held until that native render settles; repeated Play/Stop or direct render calls cannot overlap allocations. Cancellation checks also run after archive reads, byte reads and decoding, before scheduling, and after render completion. Separate opaque editor iframes have independent gates. Parent close/revoke sends `hole:stemdeck-stop`, accepted only from the parent window, which disposes the audio context, disables controls and permanently closes that transport. Frame teardown is additional cleanup. Errors retain the native document. No autoplay occurs after recovery/reopen.
