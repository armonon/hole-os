# Native Tone adjustment layers

The connected editor uses the retained Luma engine at revision `af6f0893b6b0fe28fff2be99d7f3cb39ab6aba54`: `Studio.addAdjustmentLayer` (`app/engine/studio.ts:3232`) and `updateTone` (`:4916`) call the real structural/history mutation paths. `ToneParams` is defined in `app/engine/document.ts:139`; the source studio's `toneRows` (`app/studio/studio-client.tsx:288–293`) sets exposure limits −2 to 2 and contrast/highlights/shadows/temperature/vibrance limits −100 to 100. These are the retained studio's controls, not a new claim of calibrated photographic exposure or RAW equivalence.

Native `.luma` files can add a neutral Tone adjustment and explicitly apply edited parameter fields. The adjustment changes the composite below its layer; underlying raster pixels are not rewritten. The UI passes `{...existingTone,...validatedEditedKeys}` because the retained `updateTone` replaces the full parameter object. Unknown tone/layer fields and untouched parameters remain intact. Neutral sets all six field drafts to zero before Apply. Discard clears field drafts without changing the adjustment. Undo uses native engine history, and saved native files retain editable Tone layers and original versions.

Admission is limited to unlocked top-level `adjustment-tone` layers without masks, clipping, smart sources, spatial presentation or layer transforms. Other adjustments remain preserved for the full studio. Existing 2048-edge/four-million-document-pixel limits, 64-layer maximum and 32-million-layer-pixel creation budget remain. No new SDK, grant, wrapper, network or CSP capability is introduced. This increment does not claim full group, masking, curves, levels, HSL, PSD/PSB/RAW or high-precision color parity.

Fields use the existing coalesced local recovery and flush handshake. Bounded per-layer raw strings preserve unfinished values such as `-`, without applying them to native data. Recovery retains field-only work with `dirty:false`. Native apply failures retain field drafts; a host quota failure after an accepted native edit retains its rendered pixels and blocks close until recovery succeeds. Ambiguous save acknowledgements block mutation and retry with the exact request ID.
