## Behavior and boundaries

The connected native Glyph editor now adds/updates/removes a selected pair, lists actual saved pairs, undoes native edits, and displays type using retained glyph contours and layout. Inputs are whole units within −1000…1000 and 200 pairs; zero removes a pair. Preview uses at most 80 characters and shows missing glyphs explicitly. Undo retains at most 50 snapshots and 16 MiB of serialized snapshots. Native recovery/export retains other authored glyphs, metrics, pair values and original saved versions.

TTF export contains the retained engine's real legacy `kern` table. OTF has no kerning; the UI discloses this. This work does not add pen/curve tools, shaping scripts, OpenType positioning, full source-studio parity or a new font compiler. Original routes remain available.

Unblurred family/advance edits are captured before parent serialization. Incomplete numeric/name fields, unapplied pair controls and type-preview text are retained as bounded view drafts; invalid values are not clamped or silently applied to the native font. View epochs remain pending until recovery ACK, including preview-only edits. Raw-only recovery retains a native snapshot for explicit existing recovery discovery; restoring identical bytes does not dirty or duplicate the saved native version. Close requests use a request ID, exact iframe source and nonce; a receiver is installed before editor readiness, waits for initialization, drains pending work and persists recovery before acknowledging. A live pointer stroke refuses close; finishing it retains the actual native stroke and Escape explicitly discards it. Failed recovery keeps the editor and current native work available; retry must acknowledge persistence before close. The parent also protects page unload while input/gesture/recovery/native ACK is pending. No new host grant or network permission is added.

Native save and derived export retain the exact request ID and Blob after ambiguous failure. Only an authenticated explicit QUOTA refusal renews the ticket, retaining its bytes. Clean native save is a no-op, so a recovery-checkpoint retry after an acknowledged native save does not create another version. Binding updates only after durable ACK. Unsupported or lossy native edits remain rejected by the retained validator.
