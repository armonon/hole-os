# Native rectangle and ellipse editing

This increment uses retained Luma `Studio.addShapeLayer` and `Studio.updateShape` at `app/engine/studio.ts:4376` and `:4891`, revision `af6f0893b6b0fe28fff2be99d7f3cb39ab6aba54`. The actual `ShapeStyle` contract and renderer live in `app/engine/document.ts:987` and `:2339`. No alternate shape renderer or flattened replacement document is introduced. Ownership notices and the full original studio route remain available.

Native `.luma` documents can add rectangles and ellipses and edit their X/Y, width/height, fill, stroke, stroke width and rectangle corner radius. X/Y locate the top-left geometry corner; strokes are centered on its boundary. Explicit Apply sends only edited keys to the retained engine. Unknown shape/layer fields and untouched styles stay intact, and Undo uses the engine history. Color edits accept six-digit hex colors or `none`; the stroke control maps `none` to the retained engine’s empty-string disabled stroke. Radius has no rendering effect on ellipses. Native save/reopen keeps the shape editable; original asset versions remain unchanged.

Admission is deliberately limited to unlocked top-level shape layers with identity layer transforms and no masks, smart source or spatial presentation. Grouped, transformed and other vector content remains preserved for the full studio. Documents support up to 2048 pixels per edge/four million pixels. Shape geometry plus centered stroke has the same edge/pixel cap, with positive dimensions, offsets within ±2048, stroke width 0–128 and radius at most half the shortest side. Creation retains the existing 64-layer/32-million-layer-pixel cap. No path editing, grouping, transformed-shape tool, full vector parity or new capability grant is claimed.

Unapplied fields use bounded per-layer string recovery, including partial numeric/color input. Typing does not change the native shape. The existing coalesced recovery/flush and pending-ACK guards preserve these fields through close/reopen and layer selection. Refused geometry does not create native history. A host quota refusal before Apply keeps the field draft and old shape; refusal after Apply keeps the new visible/native shape and blocks close until recovery succeeds. Ambiguous native-save acknowledgements retain the exact request ID and block further edits until retry.

The same editor now retains completed pointer strokes before starting asynchronous recovery. Previously, pointer release cleared its raw gesture before an admission checkpoint: quota failure there silently discarded the completed stroke. The repair validates and applies the real engine stroke synchronously, marks it dirty, then checkpoints. Checkpoint failure retains the pixels and Undo entry; Keep recovery does not replay the stroke. Escape/pointer cancellation still cancels unfinished strokes. Window blur preserves a pending gesture; it does not silently discard it. An actual runtime-close test with a held pointer and dispatched blur refuses close, retains the frame, and verifies Escape then permits close without changing pixels. The original runtime-focus path alone did not reproduce a blur-triggered discard in Chrome; the explicit blur branch is qualified separately.
