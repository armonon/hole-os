# Luma native copies and explicit raster exports

The connected editor uses the retained Luma Studio engine and codecs (source revision af6f0893b6b0fe28fff2be99d7f3cb39ab6aba54). Save native copy derives an application/x-luma-project ZIP from PNG/JPEG/WebP or native input. It preserves the engine's editable layer/text representation and does not mark the source saved, change its binding or replace its original version. Open the derived native asset separately to continue editing it. PNG/JPEG/WebP exports use the actual engine renderer; JPEG has a white backdrop and JPEG/WebP accept explicit quality 0.1–1.

The host persists one derived asset before success is shown, with the exact input version as its parent. Ambiguous acknowledgements retain the same request ID and exact output blob. A definitive host QUOTA rejection allows a fresh request ID with those same bytes because the broker caches failures. Pending exports block edits and unrelated saves. Cancellation before dispatch creates no output; once durable dispatch begins, cancellation is unavailable. Native ZIP/canvas encoding itself is not forcibly terminated.

Admission: up to 2048 pixels per edge, four million document pixels, 64 layers and 32 million aggregate layer pixels; encoded output at most 32 MiB. Requested raster MIME/signature and decoded dimensions are verified before dispatch. These are connected-tool limits, not full studio parity. The retained native serializer does not preserve arbitrary unknown top-level manifest/document fields; original versions remain retained, and known layer metadata is preserved.

Text recovery coalesces a typing burst into a busy checkpoint, a native snapshot and a final ready checkpoint. Dirty UI state remains immediate. The exact-frame/nonce host flush handshake waits for initialization and pending text durability before close. All checkpoint failures block close until recovery succeeds. An exact-frame/nonce pending signal lets the parent warn before browser unload during pending or failed recovery; durable recovered dirty edits alone do not warn. A browser regression types 300 individual characters using three bridge requests. The bridge still has a lifetime 256-request grant limit; long-session grant renewal is separate remaining work.
