# Local bounded video trim

`video.trim` uses actual installed ScenePilot dependency Mediabunny1.51.0, with browser WebCodecs in a module Worker. The unmodified local ESM bundle, MPL2.0 license, provenance notice and corresponding source archive reside under `src/vendor/mediabunny`. No engine download/build was performed. The existing ScenePilot retained document engine does not include rendering; this wrapper uses its actual media dependency directly.

Input pinned immutable video <=64 MiB/10 minutes, one video track and zero or one audio track, <=3840 on each coded edge and <=8,294,400 pixels. Selected range positive and <=30 seconds. Output WebM VP8 video/Opus audio, force-transcoded, with no intentional track dropping. Unsupported encoders/decoders or discarded tracks fail. Runtime60 seconds default, configurable1–120000 ms. Cancel or timeout terminates Worker; no output commit. Output stream writes capped32 MiB. Progress writes serialize before commit.

Output is re-opened by the media engine to validate video/audio track counts and duration within0.25 seconds of requested range. This is not frame-exact or lossless trim, and does not promise metadata preservation. Actual start/end/output duration, source tracks, output tracks, codec and engine are recorded in provenance alongside the exact input version. Originals remain byte-identical. Worker termination bounds execution but OS/browser codec allocation is not an exact memory quota.
