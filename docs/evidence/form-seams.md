# Form native seam binding and recovery

The connected Form editor now exposes the original `bindPatternEdges` and `patternEdgeLength` operations: explicit piece/edge A and B, six native seam types, measured edge lengths/ease ratio, Bind, Disable/Remove selected seam, and native Undo. Disable retains binding metadata. Explicit Remove deletes only the chosen binding and native workspace index entry; it refuses project relationship references. Undo restores either operation. Original full-studio routes remain unchanged. The generated engine provenance is in `src/vendor/form/README.md`.

## Persistence and interfaces

`HoleForm.create().mount(instance, root)` and its exact selected asset/version contract are unchanged. The editor adds an early exact-parent/nonce flush listener; parent serialize and direct close await it. Direct close freezes input and restores the frame and grant when the final checkpoint fails. The parent unload guard accepts only exact-frame/nonce pending signals. Runtime-wide close admission remains owned by the shared runtime.

Raw name, scene, point/allowance and seam-selection fields are bounded and durably checkpointed as strings without silently applying incomplete numbers. Switching a pattern point/piece or scene object refuses while corresponding fields are unfinished; explicit discard reloads native values. Saving native content does not implicitly apply raw fields. A successful native ACK followed by recovery failure reports the saved version and asks for recovery, rather than offering a duplicate save. Clean native save is a no-op. Ambiguous save/export retries retain exact tickets and Blobs; only an authenticated host QUOTA rejection renews a ticket.

`HoleFormAdapter` adds `seamPreview(a,b)`, `bindSeam(a,b,type)` and `disableSeam(id)` / `removeSeam(id)`. Geometry admission precedes retained parsing/tessellation: 64 pieces, 256 points/piece and 4096 total, 128 curves, 256 seams, finite ±10000 mm coordinates and bounded unique identities. Seam refs require explicit in-range integer edges and nondegenerate lengths. Existing unsupported/larger native projects remain retained; this is not full studio parity. Undo uses the original native project history with 30 entries/32 MiB.

## Export limits

DXF includes synthesized midpoint seam notches. PDF includes explicit native pattern notches but does not synthesize marks from seams. Source assets, CAD/scene/other workspaces, relationships and inferred-scan metadata remain inside the native project contract; no network source is fetched. Edge ease is a geometric ratio, not a fit or manufacturing assessment. No cloth simulation, physical scan/camera qualification or certified pattern-making accuracy is claimed.
